# Site permissions in the browser panel

When a page in the desktop app's browser panel asks to use your camera, microphone, location,
notifications, clipboard or MIDI devices, a card appears under the toolbar: **Allow** or **Block**.
Press Tab from the toolbar to reach it, or Esc to deny the request once without remembering it.

Your choice is remembered for that site, separately for each browser profile. Camera and
microphone are decided separately, so a site can have one without the other. Incognito tabs forget
their choices when the app quits.

To review or change a site's choices, open the ⋮ menu and choose **Site permissions**. Each
permission can be set to **Allow**, **Ask** (prompt again next time) or **Block**.

Agents can allow a permission for a site you have not decided on, which also answers a waiting
prompt. They cannot undo a **Block** you chose. A decision an agent made shows "set by agent" in the
menu, and you can change it.

On macOS, the first time a site you allowed uses the camera or microphone, macOS asks Cogenly for
access too. If you declined, allow it under **System Settings → Privacy & Security**.

Tabs that run in an environment's own browser, such as on a remote server, have no prompt. An agent
allows what those pages need.
