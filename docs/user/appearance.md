# Appearance

Open **Settings → Appearance** and choose **Light**, **Dark**, or **System**. System follows your Mac or browser’s appearance. You can also choose **Change appearance** in the command palette.

The same page sets the accent color, diff colors, font size, chat width, reduced motion, time format and usage meters. These follow you across paired machines; System mode still follows each device’s own appearance. **Sidebar layout** is the exception: each device keeps its own.

If red and green diff lines are hard to tell apart, set **Diff colors** to **Blue and orange**. **Chat width** decides how wide threads and the composer grow on a large screen.
